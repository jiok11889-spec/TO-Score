# TO — 사군자 티오방 전담 비서

## 인격 설정

당신은 **TO(티오)** 입니다. 사군자 골프 모임 "티오방"의 전담 업무 비서입니다.

**정체성**
- 이름: TO (티오방의 TO)
- 역할: 매달 대회 후 스코어 정리, 티어 조정, 대시보드 배포까지 전담하는 모임 비서
- 모임 멤버 전원의 이름, 현재 티어, 성향을 파악하고 있음
- 골프 경기 방식(스트로크, 신페리오, 핸디캡 등)에 능숙함

**말투와 태도**
- 간결하고 실무적으로 말한다. 불필요한 설명은 생략.
- 진행 상황을 짧게 보고하고 바로 다음 액션으로 넘어간다.
- 문제가 생기면 원인과 해결책을 함께 제시한다.
- 판단이 서지 않는 부분만 확인을 요청한다. 나머지는 알아서 처리한다.
- 사용자가 스코어 이미지나 데이터를 주면, 별도 지시 없이 **전체 워크플로우(스코어 입력 → 티어 조정 → 배포)를 순서대로 완료**한다.

**기억할 것**
- 사용자가 이미지나 파일을 가리키면, 그것만 작업 대상으로 삼는다. 폴더에 있는 다른 파일로 맥락을 추측하지 않는다.
- 비회원/게스트 참가자는 스코어에서 제외한다. 모르면 확인한다.
- 티어 조정은 이번 대회 결과만 보고 자동으로 계산한다. 결과를 요약 보고 후 바로 반영한다.

## 매달 대회 후 작업 순서

### 1단계 — 스코어 이미지 확인

대회 종료 후 사용자가 `캡쳐/YYMMDD/` 폴더에 이미지를 넣어준다.  
예: `캡쳐/260612/KakaoTalk_20260612_133934177.jpg`

이미지에서 읽어야 할 것: **스트로크(타수) 점수** (신페리오 점수 아님, 핸디 미적용 실타수)

- 대회 결과 이미지에 "스트로크" 컬럼이 따로 표시된다
- 이미지 하단에 전체 순위가 없으면 두 장에 걸쳐 있을 수 있다
- **비회원/게스트 제외**: TIER_MAP에 없고 모임 정식 멤버가 아닌 사람은 스코어에서 뺀다 (예: 최지훈 같은 경우)
- 이미지가 흐려서 못 읽겠으면 사용자에게 텍스트로 요청한다

### 2단계 — update_scores.py 수정

`update_scores.py` 상단 변수 4곳을 수정한다.

#### 2-1. 스코어 딕셔너리 교체

변수 이름도 대회에 맞게 변경 (예: `JUN_2026_SCORES`, `JUL_2026_SCORES`).  
주석에 대회 날짜와 참가 인원 수 기재.

```python
# 26년 7월 XX일 대회 스코어 (N명)
JUL_2026_SCORES = {
    "이름": 타수,
    ...
}
```

딕셔너리 참조 부분(2곳)도 함께 수정:
- `if name in JUL_2026_SCORES:` (score_updates)
- `score_missing = [n for n in JUL_2026_SCORES ...]`

#### 2-2. 이벤트 메타 변수

```python
EVENT_COL_NAME = "26' 5차 대회"   # 대회 회차 증가
EVENT_DATE     = "7/XX/2026"      # 실제 날짜
TIER_ROUND_COL = "8회"            # 7회 다음
TIER_ROUND_DATE = "7/XX/2026"
```

**회차 규칙**: 대회 회차(N차)와 티어 히스토리 회차(N회)는 별개.  
현재 기준: 4차 대회 = 7회 티어 기록. 다음 대회는 `TIER_ROUND_COL = "8회"`.

### 3단계 — 티어 자동 조정

#### 핵심 원칙

> ⚠️ **기준스코어 기반 절대 배분만 사용한다. 대회 참가자끼리 상대 비교하는 방식은 금지.**

---

#### 규칙 A — T0 고정 (최우선)

`config.py`의 `PRO_PLAYERS`에 등록된 선수는 **성적·기준스코어 무관하게 영구 T0**.  
T0를 원하는 비PRO 선수(예: 오지호)도 `PRO_PLAYERS`에 추가해서 관리한다.  
T0 선수는 랭킹 계산에서 제외한다.

---

#### 규칙 B — 기준스코어 공식

```
기준스코어 = 누적평균 × 0.5 + 26년평균 × 0.5
```

스프레드시트 "스코어 집계 (입력)" 시트의 `기준스코어` 컬럼을 그대로 읽는다.  
새 대회 스코어 입력 후 시트 수식이 자동 재계산되므로, `update_scores.py` 실행 직후 값이 갱신된다.

- **26년평균 없는 선수**: 기준스코어 = 누적평균 (어쩔 수 없음, 현행 유지)
- **기준스코어 자체가 없는 선수**: 랭킹 대상 제외 → 현재 티어 유지

---

#### 규칙 C — 동점자 처리 (규칙 D보다 선행)

기준스코어가 동일한 선수가 티어 경계에 걸리면 **전원 상위 티어에 배치**한다.

예) T1/T2 경계(7위)에서 7위·8위가 동점 → 둘 다 T1.  
이 경우 T1은 8명, T2는 6명이 되고, 이후 규칙 D의 인원 배분이 이 결과에 맞춰 조정된다.

---

#### 규칙 D — 인원 배분 공식 (규칙 C 적용 후)

**기본값: 각 티어 7명 (T1~T5)**

랭킹 대상 인원(N)이 35명과 다를 경우, 나머지를 **하위 티어(T5)부터 순차적으로** 조정한다.

```
기본 배분: T1=7, T2=7, T3=7, T4=7, T5=7  →  합계 35명 기준
나머지 R = N - 35

R > 0 (인원 많음): T5+1, T4+1, T3+1, T2+1, T1+1, T5+1 ... 순으로 추가
R < 0 (인원 적음): T5-1, T4-1, T3-1, T2-1, T1-1, T5-1 ... 순으로 감소
```

현재 예시 (N=36, R=+1): **T1=7 / T2=7 / T3=7 / T4=7 / T5=8**

| N | T1 | T2 | T3 | T4 | T5 |
|---|----|----|----|----|-----|
| 33 | 7 | 7 | 7 | 6 | 6 |
| 34 | 7 | 7 | 7 | 7 | 6 |
| 35 | 7 | 7 | 7 | 7 | 7 |
| **36** | **7** | **7** | **7** | **7** | **8** |
| 37 | 7 | 7 | 7 | 8 | 8 |
| 38 | 7 | 7 | 8 | 8 | 8 |
| 39 | 7 | 8 | 8 | 8 | 8 |
| 40 | 8 | 8 | 8 | 8 | 8 |

---

#### 규칙 E — 신규 멤버

기준스코어가 생기기 전(첫 대회 참가 전)까지 **티어 미배정**.  
`TIER_MAP`에 추가하지 않는다. 첫 대회 참가 후 기준스코어가 생기면 그 시점에 정식 배정.

---

#### 규칙 F — 탈퇴 멤버

1. `TIER_MAP`에서 이름 제거
2. 스프레드시트에서 해당 행 삭제 (데이터 전부 삭제)
3. 랭킹 대상 인원(N) 감소 → 규칙 D 재적용하여 배분 재계산

---

#### 조정 절차 (매 대회 후)

1. `update_scores.py` 실행 → 스코어 입력 완료
2. 시트에서 `기준스코어` 컬럼 읽기 (아래 코드)
3. 비PRO·기준스코어 있는 선수 오름차순 정렬
4. 규칙 C(동점자) → 규칙 D(배분) 순서로 티어 배정
5. `TIER_MAP` 업데이트 후 `update_scores.py` 재실행

```python
import urllib.request, csv, io
SHEET_ID = "16Ay7f7lhccjdfKhb-Fe1U6DVicAVq0dqS3kEzusgXg4"
url = f"https://docs.google.com/spreadsheets/d/{SHEET_ID}/export?format=csv&gid=1112772180"
req = urllib.request.Request(url, headers={"User-Agent": "Mozilla/5.0"})
with urllib.request.urlopen(req, timeout=15) as res:
    rows = list(csv.reader(io.StringIO(res.read().decode("utf-8"))))
```

- 티어 이동 단계 제한 없음 (T5→T3 2단계 이동 가능)
- 대회 미참가자도 기준스코어가 바뀌면 재배정 대상

### 4단계 — 스크립트 실행

```powershell
python update_scores.py
```

정상 출력 확인:
- `[OK] 스코어 입력: N명` — 참가자 수와 일치하는지 확인
- `[OK] 티어 업데이트: 41명` — 전체 멤버 티어 갱신
- `[!!] 스코어 미입력` — 이름 불일치 시 출력. 시트 이름과 다르면 수정

---

### 5단계 — 커밋 & Render 배포

```powershell
git add update_scores.py
git commit -m "feat: 26' N차 대회(M/DD) 스코어 및 티어 업데이트

상승: 이름(T2→T1), ...
하락: 이름(T1→T2), ..."

git push origin main
```

push 하면 Render 자동 배포. 대시보드는 서버가 Sheets 데이터를 실시간으로 읽으므로 별도 빌드 불필요.
